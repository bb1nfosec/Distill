Everything in one tool

⚡
Runtime proxy
Intercepts every LLM API call. Strips waste, injects caching, shows context fill %. Works with Claude Code, Cursor, and any OpenAI-compatible tool.
💰
Prompt caching auto-inject
Automatically adds cache_control to your system prompts and large context blocks. Claude caches them — you pay 90% less on repeat calls.
📊
Web dashboard
Token usage over time, cost by model, per-user attribution, budget status. Self-hosted with Docker. JWT auth + SSO / LDAP / Azure AD.
🔑
Secrets detection
Scans for AWS keys, OpenAI tokens, GitHub PATs, and private keys before they reach an LLM. Runs in CI with --fail for hard blocks.
🔒
CI budget gate
skim check exits 1 if the project is over its token budget. Drop into any GitHub Actions / GitLab CI pipeline in 3 lines.
📐
Baseline regression
Save a token count snapshot before a refactor. Compare after. Get a clear diff — so PR reviews catch context bloat before it ships.
